Privacy

Updated 6 November 2026

MacXray doesn't collect your data. There's no account, no analytics, no ads and no tracking, and nothing MacXray sees on your Mac is sent to us or to anyone else.

What MacXray reads on your Mac

To show you what your Mac is doing, MacXray reads what macOS reports about itself:

  • The programs running and how much memory and processor time each one uses.
  • Which files change and where. MacXray sees that a file changed, never what's inside it.
  • Network connections: which app opened them, the server and port on the other end, and how much data flows. It never sees what's sent.
  • The processor's cores, the graphics, memory, temperature state and the battery's readings.
  • The system log that macOS writes as it works.
  • What you copy to the clipboard, in every format it was copied in.

All of this stays in memory while MacXray runs and is gone when you quit it, except your clipboard history.

Your clipboard history

MacXray saves what you copy so you can find it and copy it again. The history is a file on your Mac, in ~/Library/Application Support/MacXray, and never leaves it.

  • Copies that password managers mark as sensitive are never read or saved. Neither are copies that apps mark as temporary.
  • In the Clipboard view you can delete any copy, clear everything except the copies you pinned, or pause saving.
  • To remove the history completely, quit MacXray and delete that folder.

When MacXray uses the network

Only to name the servers your apps talk to. For an address such as 17.253.144.10, MacXray asks your Mac's usual DNS server (often your router or your internet provider) for its name, just as many network tools do. Nothing else is sent: MacXray has no account, doesn't check in with us and doesn't use any online service.

MacXray's window

MacXray's window shows a page that MacXray serves to your own Mac at 127.0.0.1, an address no other computer can reach. It refuses requests from websites, so a page open in your browser can't read it. Open in Browser shows the same page in your browser, still served only to your Mac.

Permissions

MacXray doesn't need your password or administrator rights. A few readings, such as the Neural Engine's load, need administrator rights, so MacXray shows them as unavailable instead of asking for them.

This website

This website has no cookies, no analytics and no trackers, and it loads nothing from other services. GitHub Pages hosts it and GitHub Releases serves the download, so GitHub receives the usual details of each visit, such as your IP address, as described in GitHub's privacy statement.

Changes

If MacXray starts to handle data differently, this page will say so first, with a new date at the top.
